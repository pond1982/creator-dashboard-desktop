YouTubeApp Store Connect

Connect your channels

  1. Enable the YouTube Data API. In Google Cloud, select or create a project. Open YouTube Data API v3 and choose Enable. Open API Library ↗
  2. Create and restrict an API key. In Credentials, choose Create credentials → API key. Edit the key. Under API restrictions, select Restrict key → YouTube Data API v3 and save. The desktop app sends API requests directly, so leave website restrictions off. Open Credentials ↗
  3. Choose your channels. Open each channel’s public page and copy its @handle or channel URL. A channel ID beginning with UC also works.

Studio analytics

Connect Google to read watch time, subscribers gained and lost, and traffic sources for each channel.

  1. Enable both YouTube APIs. In the same Cloud project, enable YouTube Data API v3 and YouTube Analytics API. Open YouTube Analytics API ↗
  2. Configure Google Auth Platform. In Branding, enter an app name and your support email. In Audience, choose External for a personal project. If testing, add the Google accounts that manage your channels as test users. External apps in testing typically require renewed consent after seven days. Open Google Auth Platform ↗
  3. Create a desktop client. Open Clients → Create client → Desktop app. Download the client JSON and select it here. Then open each channel and choose Connect Studio analytics to grant read-only access for that channel. Open OAuth clients ↗

Connect your app sales

  1. Open team keys. In App Store Connect, open Users and Access → Integrations → App Store Connect API → Team Keys. If access hasn’t been enabled, the Account Holder can request it there. Open App Store Connect ↗
  2. Generate a reporting key. As Account Holder or Admin, create a team key with the Sales and Reports role. Copy the Key ID and Issuer ID from Integrations. Download the private .p8 file and keep it somewhere safe. Apple allows one download.
  3. Find your vendor number. In Reports (Payments and Financial Reports), look beneath your legal entity name at the top left. Enter the vendor number for your apps. Apple’s instructions ↗
